深潛計畫與電腦錶

🗺️深潛計畫：不是「跳下去再說」

深潛計畫的目標：在免減壓時間內，安全下去、安全回來。

📖 深潛計畫要素（SDI）
1. 最大深度：這次要下多深（≤40m）
2. 免減壓時間：這個深度能待多久（電腦錶算）
3. 氣量：下去+回來+安全停留要多少氣
4. 水面休息：兩次潛水間隔
5. 緊急計畫：沒氣/氮醉/失散怎麼辦
✈️ 深潛像「開飛機」——起飛前有完整的飛行計畫，每個數字都算好。
不是怕，是深處沒有犯錯的空間。

⌚電腦錶 = 深潛的儀表板

📖 深潛要看什麼
深度：不要超過計畫深度
免減壓時間：倒數到 0 就要上升
水溫/NDL：冷水免減壓更短
上升速度：電腦錶會警告你上升太快
安全停留：5m × 3 分鐘（電腦錶會倒數）
⚠️ 深潛「電腦錶是必需品」——不是選配！
而且每個人都要戴自己的（不能共用，資料是個人累積）。

🚨深潛緊急程序

  1. 氣不夠：通知潛伴 → 用備援/共享 → 慢慢上升 + 安全停留
  2. 氮醉嚴重：上升幾公尺清醒 → 通知教練 → 可能結束潛水
  3. 潛伴失散：原地找 1 分鐘 → 上升 → 水面集合
  4. 減壓病疑似：出水 → 純氧 → 送醫（知道當地高壓艙在哪）
📖 高壓艙資訊
深潛前要知道最近的減壓艙（高壓艙）在哪、怎麼聯絡。
小琉球/屏東區域：問教練當地醫療資源與轉送路線。
減壓病處理：100% 純氧 + 送醫（不是休息就好）。

✅小測驗（5 題）

1️⃣ 深潛計畫最重要的目標？

✅ 安全來回 + 不超過免減壓時間

2️⃣ 深潛時電腦錶最重要的功能？

✅ 免減壓倒數 + 上升速度警告 + 安全停留

3️⃣ 潛伴失散，深潛時第一步？

✅ 找 1 分鐘 → 上升 → 水面集合（深處不要慌）

4️⃣ 疑似減壓病的處置？

✅ 純氧 + 送醫，並告知醫療人員潛水史

5️⃣ 深潛前要知道什麼？

✅ 知道高壓艙位置/聯絡方式（減壓病的救援關鍵）

📌這章記住 3 件事

  1. 深潛 = 18-40 公尺，不是「敢下」就好
  2. 深處三大風險：氮醉、耗氣快、減壓病
  3. 深潛鐵律：照計畫、看電腦錶、慢慢上
