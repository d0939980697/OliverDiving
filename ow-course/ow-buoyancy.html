浮力與中性浮力

🎈浮力：潛水員的「超能力」

魚為什麼能停在水中不動？因為牠有魚鰾——調整浮力。你的「魚鰾」就是BCD + 肺部 + 配重的組合。

🎈 想像自己是氣球：
氣太多 → 一直往上飄（浮力太大）
氣太少 → 一直往下沉（浮力不夠）
「中性浮力」= 剛好停住，不飄不沉——這是潛水最重要的技巧。

⚖️浮力的三個狀態

狀態說明例子
正浮力（Positive）浮力 > 重力 → 往上浮水面休息、BC 充氣
負浮力（Negative）浮力 < 重力 → 往下沉下潛、戴配重
中性浮力（Neutral）浮力 = 重力 → 停在水中懸浮、看珊瑚、拍照
📖 阿基米德原理
物體受到的浮力 = 排開液體的重量。
穿防寒衣 → 體積變大 → 浮力變大（所以配重要增加）。
氣瓶用掉 → 氣瓶變輕 → 浮力變大（潛越久越容易飄）。

🛠️怎麼控制浮力

  1. 配重（Weights）：先配到「水面眼睛平水面」的程度（教練會幫你調）
  2. BCD 充氣/洩氣：大範圍調整——下潛放氣、上浮充氣
  3. 肺部微調：深呼吸=稍微上浮、淺呼吸=稍微下沉（不是憋氣！）
📖 配重原則
正確配重測試：水面、BCD 洩氣、正常呼吸——水面應該在眼睛高度。
配太少：下潛費力、一直往上飄。
配太多：要一直游、耗氣快、容易累。
快卸設計：配重帶/整合配重要有快卸扣——水面緊急時能一秒脫掉。
⚠️ 緊急情況（BCD 故障）：配重快卸是你的救命繩——水面漂浮時脫掉配重立刻變正浮力。

🫁肺部 vs 憋氣（重要！）

「用肺控制浮力」≠「憋氣」！
肺部微調是「呼吸深淺」的變化——永遠保持呼吸流通。
憋氣 = 氣體困在肺裡 → 上升膨脹 → 肺破裂風險（波義耳章節！）
🫁 想像肺部是「氣囊」：吸飽 → 體積大 → 浮力大；吐光 → 體積小 → 浮力小。
但氣囊的門（氣管）永遠開著——只是呼吸深淺不同。

✅小測驗（4 題）

1️⃣ 「中性浮力」是什麼？

✅ 停在水中不動（浮力=重力）

2️⃣ 潛水越久，氣瓶變輕，浮力會？

✅ 變大（氣瓶變輕 → 浮力變大 → 越潛越容易飄）

3️⃣ 配重正確的測試標準是？

✅ 水面、BCD 洩氣、正常呼吸時眼睛平水面

4️⃣ 用肺部控制浮力時要注意？

✅ 保持呼吸流通（憋氣 = 肺破裂風險）

📌這章記住 3 件事

  1. 水越深氣越小、越淺氣越大（P₁V₁=P₂V₂）
  2. 上升絕不憋氣，速度 ≤ 9-18 公尺/分鐘
  3. 最後 3-5 公尺最危險，安全停留 5m × 3 分鐘
