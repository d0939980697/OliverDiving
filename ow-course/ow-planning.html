潛水計畫與潛伴

🗺️潛水前先計畫，計畫完才下水

潛水不是「跳下去再說」——每一次潛水都應該有計畫。

✈️ 飛行員起飛前有 checklist，潛水員下水前也有——
不是因為怕，是因為意外總發生在沒準備的人身上。

🤝潛伴系統（Buddy System）

永遠不要一個人潛水。潛伴 = 你的第二條命。

  • 下水前跟潛伴討論計畫（深度、時間、路線、失散怎麼辦）
  • 下水後保持在彼此看得到的距離
  • 失散 SOP：找 1 分鐘 → 水面找 1 分鐘 → 上升水面集合
  • Buddy Check：下水前互相檢查裝備（你檢查我、我檢查你）
💡 潛伴檢查口訣（BWRAF / 或台灣常用「潛伴互檢」）：
氣源開沒開、BCD 好不好、配重、殘壓、緊急計畫——互相檢查一次，省一條命。

🚤船潛 vs 岸潛

船潛岸潛
進出背滾式/跨步入水，梯子上船自己走下水
注意聽船長/教練簡報、別離船看浪、看潮汐、別走太遠
暈船可能（先吃藥）較少
⚠️ 船潛鐵律：聽簡報！船長會說集合時間、緊急程序、水流資訊——別滑手機。

💪體能與過度勞累

  • 潛水需要體力：前一天睡飽、當天吃飽（但別吃太撐）
  • 扛裝備、逆流游 → 很累 → 累了容易慌、容易出錯
  • 感覺喘不過氣 → 停下來、抓穩、深呼吸，不要硬撐
🏊 潛水不是比賽！
「慢慢來」才是專業——快不是英雄，穩才是。

⛑️急救常識（先知道有這些）

  • 潛水意外 → 判斷呼吸心跳 → 叫救護 + CPR
  • 氧氣急救：潛水意外現場給純氧是標準處置（O2 課程會教）
  • 減壓病 → 高壓艙治療（小琉球最近在哪要問教練）
  • EMT 急救證照課程：建議學（教練會推薦）

✅小測驗（3 題）

1️⃣ 潛伴失散了，第一步是？

✅ 原地找 1 分鐘 → 水面找 1 分鐘 → 上升集合

2️⃣ 為什麼要潛伴互檢？

✅ 檢查裝備——你的命可能在潛伴手上

3️⃣ 潛水時覺得喘不過氣？

✅ 停下來、抓穩、深呼吸（累了就休息，別硬撐）

📌這章記住 3 件事

  1. 永遠不單獨潛水，潛伴是第二條命
  2. 下水前 計畫 + 互檢（氣源/BCD/配重/殘壓）
  3. 累就休息、慌就停——穩才是專業
