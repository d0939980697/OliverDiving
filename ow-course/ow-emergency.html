🚨 緊急程序

潛水出狀況怎麼辦？先讀過，才不會現場慌

💡為什麼要「先讀」緊急程序？

潛水的緊急狀況很少見，但發生時沒有時間慢慢想。

這章把最重要的狀況和步驟整理出來——先有概念，現場才不會慌。教練會帶你實際練習，這章是「預習」。

📖 白話比喻：像滅火器——平常不會用，但火災時你必須「反射動作」就拿起來噴。潛水緊急程序也是一樣，練到變反射動作就對了。

⏱️緊急減壓（Emergency Decompression）

OW 課程不教你「減壓潛水」——減壓停留只出現在「意外」時：你不小心超過了免減壓時間（NDL）。

專業標準（SDI）

如果意外超過免減壓時間，你有生理上的義務在上升前做「分段減壓停留」：

  1. 電腦錶會顯示減壓停留深度與時間
  2. 以正常速度上升，在第一個減壓深度停下
  3. 待滿所需時間 → 電腦錶顯示下一個較淺的停留深度
  4. 完成所有停留，直到電腦錶允許你上升到水面

⚠️ 前提：你的氣量要夠才做得到。

🚫 沒氣又不夠做停留？→ 見下一段「遺漏減壓」。

🫁遺漏減壓（Omitted Decompression）

如果真的發生：進入減壓模式，但氣不夠做完整停留（也沒辦法跟潛伴借氣）——只能先回水面，但「程序」要馬上啟動：

✅ 水面後：建立正浮力、打浮力袋/求援信號
✅ 上船後：立刻告知潛水主管「我遺漏減壓了」
✅ 吸氧：純氧至少 30 分鐘
✅ 觀察：至少 24 小時注意減壓病症狀
✅ 禁止：24 小時內不可再潛水、不可搭飛機、不可去高地
🛑 白話：遺漏減壓不是「回水面就沒事」——是「上岸才開始處理」！氧氣 + 觀察 + 求醫，一個都不能少。

⌚電腦錶故障（Computer Failure）

電腦錶是你潛水紀錄的唯一真相——它掛了：

  • ✅ 沒有備用電腦錶 → 直接中止潛水（因為不知道你的潛水剖面）
  • ✅ 氣夠 + 離免減壓上限還遠 → 做安全停留後上升
  • ✅ 送修 + 等 24 小時再潛（避免重複潛水殘氮問題）
專業標準（SDI）

有些電腦錶在違反減壓規範後會「鎖機」：24 小時內不再提供/追蹤潛水資訊，甚至潛水途中就鎖住（只顯示深度和時間）。

💡 選電腦錶時，挑會顯示「緊急減壓需求」的款式——這能救你一命。

😱恐慌（Panic）

恐慌是水裡最危險的狀況之一。恐慌的人無法理性思考，通常無法自救，要靠別人救。

恐慌來自焦慮——環境陌生、裝備不舒服、看不到底、呼吸急促⋯⋯

🧘 白話：恐慌 = 大腦當機。跟電腦一樣，當機時你亂按什麼都沒用。預防 > 處理：呼吸慢一點、手抓穩、跟緊潛伴、別勉強。
🚨 看到潛伴恐慌：停下來、抓穩他、眼神接觸，用「OK」手勢引導他慢慢呼吸——不要急著拉他上升！

🏃過度用力 / 水面問題

過度用力（Overexertion）：游太快、逆流硬撐 → 喘不過氣 → 恐慌風險大增。

  • ✅ 慢下來、休息、抓可抓的東西
  • ✅ 告訴潛伴「我累了」（用國際手勢：手掌平放左右擺）
  • ✅ 不要硬撐——潛水永遠可以「下次再來」

水面問題：

  • ✅ 建立正浮力（BCD 充氣、丟配重）
  • ✅ 吹口哨/舉浮力袋/揮手
  • ✅ 不會游泳的人：抓住可漂浮物、保持鎮定、等救援

🧑‍🤝‍🧑潛伴失蹤（Missing Diver）

潛伴沒按時間浮出水面：

✅ 1. 通知水面主管：你和潛伴失散了
✅ 2. 提供資訊：最後位置、潛水時間、最大深度
✅ 3. 超過合理時間未浮出 → 由合格潛水員搜索 + 通報當地救難單位
💡 最好的處理 = 預防：不要跟丟潛伴！三不五時回頭確認，潛伴是你在水裡最大的保險。

🌊暈船（Seasickness）

暈船 = 船的搖晃干擾了耳朵的平衡機制 + 視覺錯亂。

專業標準（SDI）
  • 船出發前組好裝備
  • 航行中遠離廢氣、待在船身最穩的地方
  • 看地平線，不要看船上物體
  • 出發前吃正常份量，避免油膩大餐
  • 多喝水，避免碳酸/咖啡因飲料
  • 防寒衣到潛點前再穿
⚠️ 暈船藥要在出發前 30 分鐘以上吃——上船後吃沒用！有些暈船藥在高壓下會有副作用，請先問醫生。
😌 好消息：一下水，暈船感通常「立刻消失」——水中是平的！

🆘減壓病急救（DCS First Aid）

懷疑減壓病 → 全部當作減壓病處理（不要自己判斷是輕是重）：

✅ 1. 把傷者帶離危險
✅ 2. 啟動緊急醫療系統（EMS / 119）
✅ 3. 監測生命徵象（脈搏/呼吸），需要時 CPR
✅ 4. 有呼吸 → 用需求調節器給 100% 純氧
✅ 5. 聯絡 DAN（Divers Alert Network）：+1-919-684-9111（24 小時免費熱線）
🏥 白話：減壓病多半需要高壓艙治療——但「先給氧」是第一線救命動作。氧氣 + 熱線 + 送醫 = 標準三步。

⛑️急救（First Aid）

常潛水的人，強烈建議學救援課程 + 基本救命術（CPR）——關鍵時刻真的能救人命。

  • ✅ 潛水急救包除了基本用品（繃帶/消毒/剪刀/膠帶/手套），還要準備：嫩肉精或醋（處理海洋生物刺傷）+ 純氧
  • ✅ 偏遠潛點（離醫療遠）風險更高 → 更要會急救
  • ✅ 急救只是「第一反應」——最終還是要找專業醫療
💡 SDI 有 First Response Training International 救援/急救課程，學完你對潛水安全會更有信心。
