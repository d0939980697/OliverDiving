壓力與平衡

👂為什麼耳朵會痛？

下潛時，水壓增加，把你耳內的氣腔「壓扁」。如果不平衡，耳朵就會痛，像坐飛機下降時那樣——但水裡更明顯。

🍿 耳朵裡有一個氣腔（中耳），連接鼻子的「通氣管」（耳咽管）。下潛時外面壓力大 → 氣腔被壓小 → 耳朵痛。就像捏扁的寶特瓶——要打開蓋子讓空氣跑進去。
📖 解剖小教室
中耳（Middle Ear）：含空氣的腔室，靠耳咽管（Eustachian Tube）連到鼻咽。
下潛時外壓增加 → 中耳氣壓相對變低 → 耳膜被往內推 → 疼痛。
平衡（Equalization）就是把空氣「送」進中耳，讓內外壓力一致。

🤧平衡（Equalization）怎麼做

最常用：瓦薩爾瓦動作（捏鼻鼓氣）

  1. 捏住鼻子
  2. 閉嘴，輕輕「鼓氣」到耳朵
  3. 聽到「啵」一聲 → 平衡成功
📖 其他方法
吞口水 / 搖下巴（Toynbee）：吞嚥動作張開耳咽管。
打哈欠：張嘴大幅移動下巴。
重點：下潛要「早平衡、常平衡」——不要等痛了才做，每下 1-2 公尺就平衡一次。
⚠️ 重要：耳朵痛 = 立刻停止下潛，上升一點點、重新平衡，再繼續。絕對不要硬撐！硬撐 = 耳膜破裂風險。

🫁肺部與面鏡的空腔

  • 肺：上升時氣體膨脹 → 一定要正常呼吸（波義耳章節講過）
  • 面鏡：下潛時面鏡會被「吸住」→ 鼻子呼一點氣進去就平衡了
  • 牙齒/鼻竇：感冒、鼻塞時空腔不通 → 不要潛水！
📖 面鏡平衡技巧
面鏡空間小，下潛時外壓變大 → 面鏡像「吸盤」貼臉（擠壓傷）。
解決：從鼻子呼一點氣進面鏡 → 內外壓力平衡 → 面鏡恢復。
鼻竇擠壓：額頭/牙齒痛 = 鼻竇空腔被壓 → 無法平衡 → 上升一點，仍痛就取消潛水。
😷 感冒鼻塞就像「氣腔的蓋子卡住了」——下潛會痛、上升會痛，嚴重會受傷。感冒就取消潛水，沒有第二句話。

✅小測驗（4 題）

1️⃣ 下潛時耳朵痛，正確做法是？

✅ 停止下潛、上升一點、重新平衡（硬撐會傷耳膜）

2️⃣ 最常用的平衡方法是？

✅ 捏鼻鼓氣（或吞口水、搖下巴）

3️⃣ 面鏡被吸住怎麼解？

✅ 鼻子呼一點氣進去就平衡了

4️⃣ 感冒鼻塞可以潛水嗎？

✅ 不可以！感冒/鼻塞 = 取消潛水

📌這章記住 3 件事

  1. 水越深氣越小、越淺氣越大（P₁V₁=P₂V₂）
  2. 上升絕不憋氣，速度 ≤ 9-18 公尺/分鐘
  3. 最後 3-5 公尺最危險，安全停留 5m × 3 分鐘
