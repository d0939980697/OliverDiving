潛水計畫與畢業

🗺️DPV 潛水計畫

📖 SDI §12.5 計畫要素
1. 水面休息（兩次潛水間隔）
2. 最大免減壓時間（電腦錶）
3. 電池續航（來回夠不夠）
4. 氣量（去回 + 安全停留）
5. 折返點（電/氣/距離）
6. 潛伴/隊伍編制
🧮 DPV 潛水計畫 = 一般潛水計畫 + 「電池數學」。
把電池當第二顆「氣瓶」——來回都要留夠！

🧼潛後保養（SDI §12.9）

  • 淡水沖洗：鹽分會腐蝕，用完立刻沖
  • 電池：按說明充電/存放（不要過放）
  • 螺旋槳/軸：檢查纏繞物、清潔
  • 存放：陰涼乾燥、避免陽光直射
  • 運輸：固定好，避免碰撞
💡 好好保養 = 下次出遊不故障！水推是高價裝備，值得照顧。

🤿課程 2 次潛水（你會經歷的）

📖 第 1 次潛水
潛水計畫 → 正確入水 → 水面使用 DPV → 帶 DPV 下潛 → 監測 DPV 和耗氣 → 上升出水 → 記錄潛水
📖 第 2 次潛水
潛水計畫 → 入水下潛 → 水下巡遊（tour） → 上升出水 → 記錄潛水
🎯 學完：你就能安全騎水推探索更廣的水下世界！

✅小測驗（5 題）

1️⃣ DPV 潛水計畫多了什麼要素？

✅ 電池續航、折返點——把電池當第二顆氣瓶

2️⃣ 潛完 DPV 第一件事？

✅ 立刻淡水沖洗，防鹽分腐蝕

3️⃣ 電池存放原則？

✅ 避免過放、陰涼乾燥（電池健康關鍵）

4️⃣ 課程第 2 次潛水主要內容？

✅ 第 2 次：水下巡遊（實際騎乘探索）

5️⃣ DPV 課程師生比（開放水域）？

✅ 2:1！水推風險高，配比最嚴

📌這章記住 3 件事

  1. 水推是「交通工具」，不是「玩具」——安全第一
  2. 電池續航 = 你的回程票——記得折返點
  3. 水推風險：螺旋槳、故障、失散——靠訓練與潛伴
